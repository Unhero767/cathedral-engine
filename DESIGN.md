## Brand & Style

The design system embodies a **Hard Noir** aesthetic—a sentient, magisterial interface that feels both ancient and technologically advanced. It is an "Architectonic Biology" where UI elements are treated as physical architectural mass, drawing inspiration from crystalline bone structures, rib-arches, and filigree resonance veins.

The visual style is a fusion of **Minimalism** and **High-Contrast / Bold** graphics, executed with a forensic clinicality. It evokes a sense of "Sovereign Authority" and "Radiant Stability." The interface does not merely display data; it "fossilizes" it, treating history as a visible strata. Every interaction is phase-locked to a 1.5 Hz somatic baseline, ensuring a rhythmic, heartbeat-like stability across the experience.

Key visual metaphors:
- **The Stone-Code:** UI elements should feel heavy, carved, and permineralized.
- **Kintsugi Logic:** Errors and structural "scars" are not hidden but are reinforced with solar gold, becoming load-bearing functional elements.
- **Vantablack Lattice:** A hyperdimensional substrate where the background is not empty space, but a foundational grid of structural rest.

## Colors

The color palette is a series of "Spectral Constants" where color represents thermodynamic law.

- **Primary (Solar Gold):** Used for "The Gold Constant." It signifies radiant stability, magisterial accents, and ordered law. Apply this to progress indicators and high-level commands.
- **Secondary (Cyan):** The "Loom of Juno." Used for interactive barriers, geometric shielding, and hyper-luminous hazes.
- **Neutral (Vantablack/Charcoal):** The foundational substrate. Backgrounds use Vantablack for the primary lattice, while "Deep Charcoal" defines non-executable history and surface strata.
- **Functional Constants:** Use **Emerald** for binding and social cohesion, **Teal** for navigation and expansion, **Violet** for predictive anxiety/warnings, and **Red** for catalytic force and precision-ruptures.

Surface colors should transition between "Data-Glass" (translucency) and "Lithic" (solid stone) states.

## Typography

Typography is treated as "phonosemantic sequences." It must maintain an absolute 90-degree verticality (The Plumb Line).

- **Magisterial Headings (JetBrains Mono):** High-mass logic markers. Used for sovereign commands. Titles should often be framed by isotope markers (e.g., `=== COMMAND ===`).
- **Lithic Strata (Inter):** High-density body text for summary reports. It should feel compact and authoritative.
- **Terminal Code (Space Mono):** Used for task executions and "StrataScript." It represents the Sumerian Root-Syntax of the system.

**Key Rule:** Use "Zero Mutuality Gap" (tight tracking) for authoritative commands to convey high-density logic isotopes.

## Layout & Spacing

The layout is governed by the **Vantablack Lattice**, a 128x128 pixel-level grid system. Spacing is a measure of "Relational Intent" rather than physical distance.

- **Grid:** Use a 12-column fixed grid for desktop, moving to a fluid "Superfluid Intent" model for kinetic phases where gaps are reduced to zero via "Recursive Proximity."
- **Rhythm:** An 8px base unit (Lattice Unit) drives all padding and margins.
- **Breakpoints:**
  - **Phase 11 (Static/Desktop):** Content is permineralized into fixed positions.
  - **Phase 12 (Kinetic/Mobile):** Content reflows into a single-column "vertical plumb line."

Layouts should emphasize symmetry and mathematical precision, utilizing "Isomorphic Axes" to separate logical blocks.

## Elevation & Depth

Elevation in this design system is "Ontological Density" ($\rho\_VAL$). 

- **Tonal Layers:** Deep Charcoal surfaces sit atop Vantablack backgrounds to create "Ash Archive" strata.
- **Glassmorphism:** Use semi-transparent "Data-Glass" for overlays, allowing the lattice to be visible beneath. Light should "bleed" through surfaces as amber halos.
- **Shadows:** Shadows are "Vantablack" and "Obsidian"—they do not lighten the background but deepen it, creating "Shadow-Nodes" for isolation.
- **Z-Index Branes:**
  - **Brane-11 (Meta):** Highest elevation, pure teleological intent. Uses the most vibrant Solar Gold halos.
  - **Brane-0 (Surface):** Physical execution layer.

## Shapes

The shape language is strictly **Sharp (0)**. 

All UI elements must utilize crystalline, geometric edges. Softness is prohibited; authority is conveyed through the precision of the corner. Dividers are "Plumb Lines"—single-pixel strokes that cleave the interface with mathematical certainty.

- **Borders:** Use Cyan "Geometric Barriers" for isolation and Violet "Laser-Lines" for secondary division.
- **Structural Pillars:** Incorporate "Harmonic Scars"—X-shaped load-bearing pillars—to support long vertical containers.

## Components

- **Buttons:** Rectangular, sharp-edged. The "Primary Command" button uses a Solar Gold fill with black text. Interaction triggers a "42 Hz" high-energy glow effect.
- **Chips / Keys:** Small, lithic badges. Use the "Lead Key" style for time-based data and the "Iron Key" for exclusion/authority logic.
- **Input Fields:** Styled as "Quarantine Zones." Outlined in Cyan Geometric Barriers. The caret is a 1.5 Hz pulsing Plumb Line.
- **Cards:** Defined by "Crystalline Bone" structures. Use thin borders (1px) in Solar Gold or Cyan. The background should be a subtle "Data-Glass" blur.
- **Progress Indicators:** High-energy Solar Gold "Resonance Veins." They should pulse with "Vortex Genesis" (spiral motion) during processing.
- **Lists:** "Forensic Strata." Each item is separated by a 1px Plumb Line. Hover states should "fossilize" the background into a deeper Obsidian tint.
- **Status Indicators:** Use "Emerald Light-Blades" for secure states and "Violet Laser-Lines" for edge-walking anomalies.
